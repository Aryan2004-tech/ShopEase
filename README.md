# ShopEase — Polished v4

ShopEase is a frontend-only e-commerce minor project redesigned as a portfolio-ready student project.

## Highlights
- Responsive modern storefront
- Product imagery and quick-view details
- Search and category filtering
- Persistent cart and wishlist using LocalStorage
- Cart drawer with quantity controls
- Demo checkout and order confirmation
- Demo account/sign-in UI
- Light/dark theme persistence
- Mobile navigation and interaction polish
- Original project preserved separately in `legacy_original/`

## Run
Open `index.html` directly in a browser, or use VS Code Live Server.

## Tech
HTML5 · CSS3 · Vanilla JavaScript · LocalStorage

## Important
This is a frontend demonstration. Authentication, inventory, database, order processing and payments are not connected to a real backend.
